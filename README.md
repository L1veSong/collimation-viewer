# 光轴校准查看器（网页版）

电子准直器 / 自动准直仪（UVC 摄像头）的网页查看器：同心圆标线、十字分划、偏心像素读数、数字变焦、截图保存。

## 在线使用

打开 https://l1vesong.github.io/ocal-viewer/ （任意浏览器；iPad 建议用 Safari）

- Mac 用户：也可使用桌面版（本地服务 + 双击即用的应用外壳）
- iPad（USB-C / iPadOS 17+）：Safari 打开本页 → 分享 → 添加到主屏幕，可全屏当 App 使用
- iPhone：系统不支持外接 USB 摄像头

## 部署到你自己的托管

本目录全部为静态文件（index.html + 主屏图标），复制到任意静态托管（自有服务器 / GitHub Pages / Gitee / 对象存储静态网站等）即可，无需任何后端。

## 说明

- 页面不上传任何数据；摄像头画面仅在本地浏览器与设备之间直接传输。
- 需在 HTTPS 或 localhost 环境下使用（浏览器对摄像头访问的安全要求）。
